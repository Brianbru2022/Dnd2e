# Old School Character Forge

A modern interactive-fiction RPG project inspired by classic tabletop role-playing mechanics and early text adventures.

## First milestone

The first playable component is the **Character Forge**: a rules-driven character creation screen with deterministic ability generation and a reusable character data model.

## IP approach

This project uses original UI, prose, names, artwork, and code. It can implement game procedures and mathematical mechanics while avoiding copied rulebook text, protected artwork, logos, setting lore, and other proprietary expression.
